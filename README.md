# TTS Builder

This website is for the [TTS Pet](LINK_TBD) extension for [Bearnoby Tools](https://bearnoby.itch.io/bearnoby-tools), a desktop app for Twitch streamers.

TTS Pet reads channel point redeems aloud through custom voices and animates an on-screen pet while it speaks. This page lets viewers pick a redeem and a voice, listen to voice samples, add suggested emotions and sounds, and build a message to paste into the redeem.
